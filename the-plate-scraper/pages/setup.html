🗄 MySQL Wizard

Point The Plate Scraper at a MySQL database: create the database, apply the schema, migrate every recipe and member, and flip the live store. The JSON file stays as a hot backup either way. On Windows you can skip all of this and let setup-theplatescraper.ps1 do it in one command.

Connection

The same details MySQL Workbench or mysql -u root -p would use.

Create database + schema

Runs CREATE DATABASE IF NOT EXISTS and the full data/schema.sql — 11 tables for users, sessions, recipes, substitutions, affiliate stores/products/links/clicks, RSS feeds, rewritten posts, and meta. Nothing is dropped; existing tables are left untouched. On shared hosts (InMotion cPanel etc.) create the database in cPanel first (it may carry a cPanel-username prefix) and enter its exact name above — this step then simply applies the schema to it.

Migrate data

Copies the whole JSON store — recipes, members, saved lists, affiliate stores & click history, feeds, posts — into the tables you just created. Safe to re-run: tables are rebuilt from the JSON mirror, which is the source of truth for this step.

Activate

Flip the live store to MySQL. Every read/write now goes to the database, and the JSON file keeps mirroring every change as a hot backup. If the database is ever unreachable, the server falls back to JSON automatically so the site never goes dark.

Prefer the terminal?

The exact same wizard runs headless — this is what setup-theplatescraper.ps1 calls under the hood:

python tools\mysql_setup.py --host 127.0.0.1 --user root --password *** --database theplatescraper --test
python tools\mysql_setup.py --host 127.0.0.1 --user root --password *** --database theplatescraper --create
python tools\mysql_setup.py --host 127.0.0.1 --user root --password *** --database theplatescraper --migrate
python tools\mysql_setup.py --host 127.0.0.1 --user root --password *** --database theplatescraper --activate

# or the whole ride in one shot (Windows):
powershell -ExecutionPolicy Bypass -File .\setup-theplatescraper.ps1
